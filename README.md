A small cross-platform C++ endpoint telemetry agent built as a practical exercise in modern C++ and OS-level programming. The agent collects basic process/system information and reports telemetry to a central UDP collector.

This project is intentionally minimal. It serves as a foundation for experimenting with Windows/Linux APIs, systems programming, security telemetry, and eventually malware detection engineering.
